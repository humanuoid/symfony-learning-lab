# VCS

Version control setup and conventions for this project.

## Platform

- GitHub: https://github.com/humanuoid/symfony-learning-lab
- Current branch: chore/tools

## Conventions

- Main branch: main
- Feature branches: descriptive names (e.g., feat/add-user-auth, refactor/service-layer)
- Commit messages: conventional commits (feat:, fix:, refactor:, etc.)
- Pull requests: required for merging to main

## Workflow

- Create feature branch from main
- Commit changes with clear, atomic messages
- Open PR for review
- Merge with squash or rebase

## Git hooks

- None configured currently
